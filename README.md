
# Elite Enterprise Angular + Spring Boot Platform

Top 1% enterprise-grade full-stack system inspired by USPS, Oracle, IBM, and AWS GovCloud.

## Features
- Angular 17 (standalone, guards, interceptors, RxJS)
- Spring Boot 3 (Java 17)
- JWT authentication + RBAC
- Secure REST APIs
- PostgreSQL + JPA
- Redis caching
- Kafka event stubs
- Docker & docker-compose
- Production-ready structure

## Run (Quick)
